2.6 风险提示（华东）

🔴 高优先级

  1. LA/LB 港口看守人工会（Watchmen's Union）已授权罢工，最早 11 月 1 日（今日）。该工会仅占港口劳动力约 2%，但负责多数码头的安全岗覆盖，一旦停工，8 个码头作业可能中断，叠加既有铁路延误，冲击会被放大（Freightos，10-29）。谈判仍在进行，今日需盯 Clark 消息。
  2. 10-30 欧洲／地中海跨国港口行动已实际发生：22 国 113 个港口、超 25 个工会参与；实际受影响枢纽包括比雷埃夫斯（约 3,000 名码头工人与海员参加，赴希腊岛屿渡轮暂停）、瓦伦西亚、勒阿弗尔、阿尔赫西拉斯、热那亚、丹吉尔地中海港、印度那瓦舍瓦。勒阿弗尔港提示 10-30 06:00 至 10-31 06:00（当地时间）集装箱码头运营受影响。影响量级口径分歧较大（组织者称影响地中海超 40% 货运、单日约 4 万箱／超 20 亿美元；另一团体称 5.2 万箱／28 亿美元；热那亚港发言人称当地影响有限）——三个口径均未获独立核实，建议按"到港窗口延误 3–5 天"做预案，而不要按最悲观数字承诺客户。
  3. 11 月 1 日欧盟小包新规首日：PID 缺失／错误会导致清关延误、扣留甚至平台侧直接下架。昨日发运的小包今日起进入欧洲首日通关检验高峰。

🟡 中优先级

  1. 甩柜与跳港常态化：全球港口拥堵占用约 12% 船舶运力，"计划运力 ≠ 可用舱位"。在环形航线布局下，部分干线船在东南亚港口提前装满后出现临时跳港、不再挂靠原定中国港口。极端案例：赫伯罗特因马尼拉三港拥堵已暂停该三港全球新订舱至 12-31。
  2. 劳方日历（上期整理，本期未获得更新确认，请按"待核实"处理）：11-05 法国全国行动、11-11 西班牙 24 小时全国总罢工、11-20 意大利分行业罢工、11-23 当周比利时全国总罢工（安特卫普—布鲁日为核心）。
  3. 霍尔木兹／黑海安全持续恶化：10-29 英国海上贸易行动办公室通报一艘油轮驶出霍尔木兹海峡时被不明发射物击中；上周仅 2 艘船通过该海峡。能源成本可能被再度推高。
  4. 查验：美线舱位向科技货倾斜，普货被甩概率上升；带电／带磁货 DG 审批通常需额外 5–7 天。本期未取得 10-30 之后新的查验率统计。

2.8 报价建议（华东）

给销售（对内）

  1. 本周华东最重要的一句话：不要拿涨价函去报价，拿开舱价去谈。 船司宣涨 4,200–4,500 美元/FEU，但实际最低成交只有 2,935（赫伯罗特）–3,500（MSC/ONE/OOCL/CMA）。客户如果看到了涨价函，你可以用这两个数字的落差直接建立专业信任。
  2. 欧线报价有效期收紧到 7 天以内，并在报价单注明"以订舱当日船司牌价为准"。理由是亚欧停航从 8 班降到 4 班、苏伊士复航到 52%，供给端每周都在变。
  3. 美线从"抢舱"转向"锁利润"。旺季已退坡、NRF 预测 11 月 −11%，此阶段优先谈长约／锁量，而不是用现货低价抢单。
  4. 英国线单独加权目的港成本。费利克斯托超 48h 占 45%、中位停留 43h，比欧洲大陆高出一个量级；内陆卡车距离长（苏格兰 600 公里以上），务必单独列 inland 费用。
  5. 空运报价拆三段：基础运价 + 燃油/安全附加（11 月旺季附加集中上调 5%–15%）+ 清关税费与尾程。低报价高结算的争议绝大多数出在后两段没写清。

给客户（对外）

  1. 欧洲小包客户：PID 今日必须补齐完毕。11-1 起 2 欧元/品类处理费 + 7 月已生效的 3 欧元/品类关税 + PID 强制申报三重叠加，海关后果是延误补税，平台后果是直接下架断单——后者损失更大。
  2. 海运欧洲客户：把 10-30 罢工的到港延误按 3–5 天做预案，并提前确认目的港免堆期、提箱预约。若有冷柜，务必注意欧洲冷柜滞箱费约 350–395 欧元/天（约为干柜 2 倍）。
  3. 空运客户：不必为"涨价函"恐慌，但要为"缺舱"留出前置期。建议美线提前 5–7 天订舱，旺季爆款 2–3 周。
  4. 美国进口客户：现在是谈长约的窗口。运力转松、不同联盟船司报价分化明显，可借此锁定来年合约。
  5. 铁路/卡航客户：不要按名义时效倒推交期，必须把口岸排队写进时效条款或采用区间时效。

FBA干货 #304｜FIST 与 ShipTrack2026-10-31

FIST（FBA Inbound Shipment Tracking，由 ShipTrack 升级而来的入仓货件追踪体系）让认证承运商把轨迹、ETA 和送达时段自动回传卖家后台；ShipTrack 就是卖家在后台看到的那个轨迹界面。

  1. 先分清几个概念：SPN 是服务商基础准入，SEND 是亚马逊合作承运方案，FIST 是入仓追踪体系，AGL 是亚马逊自营物流，四者不等价。
  2. 功能要按需筛选：FIST 三项能力为 ShipTrack（轨迹与 ETA）、DW Automation（送达时段自动更新）、SR 智能转仓。每家承运商支持的功能不同，需在 SPN 的 FIST 页面按标签筛选；FIST Elite 是绩效更严、三项全支持的优选承运商，名单每月更新。
  3. 建单别漏权限：在“确认发货”选择第三方／FIST 承运人后，须勾选“允许承运人自动更新我的送达窗口”，否则 DW 自动化不生效；轨迹在【货件一览】-【承运人更新】查看。
  4. 时段别填太近：系统来不及自动刷新就会被判迟到；目前主要覆盖美加站点，并非所有线路、仓库和账号都支持，以 Seller Central 实际可选项为准。
常见坑：以为选了 FIST 承运商就自动拥有全部能力——权限没勾选、承运商本身不支持 ShipTrack／DW，后台轨迹仍旧空白，迟到申诉拿不出 POD 和轨迹证据，还会留下入仓缺陷记录。
风控#304 报价前先分清：指数价、船司公告价、成交价2026-10-31

客户拿到的三个数字常常来自三个完全不同的口径，混着用就会在结算时吵架。报价前先确认自己说的是哪一种。

  1. 指数价／基准价：交易所或咨询机构发布的周度参考，如 SCFI、CCFI、SCFIS、德路里 WCI、Freightos FBX。它们是宏观走势标尺，不是你的成交价。
  2. 船司公告价（涨价函／FAK）：承运人对外公示的目标费率，反映的是"想卖多少"，落地与否取决于货量。
  3. 实际成交／开舱价：订舱当天真正能拿到的价格。当"公告 4,200–4,500 而实际开舱 3,000"出现时，两者差额就是你的议价空间。
  4. 报价单要写清：基准来源、公布日期、是否含燃油附加与旺季附加、有效期、以及"以订舱当日船司牌价为准"这一句。
  5. 跨口径不要混算：德路里 WCI 是上海单港中位数，Freightos FBX 是亚洲区域加权，同一周出现方向相反属正常现象，向客户说明用的是哪一家即可。
常见坑：拿指数价去答应客户、拿涨价函去做预算，结果实际结算和承诺对不上，信任成本远高于那点差价。
FBA#303 FBA 预约入仓与送达时段管理2026-10-30

卡派送仓不是货到就能卸货，货件必须持有有效的预约（Appointment）和送达时段（Delivery Window）；亚马逊按这个时段判断是否迟到，而不是按你在后台填的预计到达日。

  1. 先分清谁来约：亚马逊合作承运人由亚马逊分配时段；自选/自有卡车的 LTL、FTL 需先在 Seller Central 填写承运人信息，再由承运人在亚马逊预约系统（Carrier Central）取得预约号并回填，预约号必须与货件号一一对应。
  2. 提前量比想象的大：旺季热门仓库的可用时段常排在 3—7 天后，部分大件仓更久；改约、取消通常要在时段开始前 24 小时操作，逾期可能产生取消费或空驶费。托拍、整车必须预约，快递包裹走免预约通道。
  3. FIST 与 ShipTrack 要留证据：承运人须按 FIST 以 API 回传车辆位置，卖家才能在 ShipTrack 看到实时进度、ETA 和送达时段变化；未接入 FIST 的货件轨迹缺失，一旦被判迟到很难拿出有效申诉材料。
  4. DW 会自己变：送达时段随路况、提柜和仓库作业滚动刷新，司机排班和卸货安排应以发货前最后一次刷新为准，不要锁死建单时的原始窗口。
  5. 迟到怎么救：在后台「入库问题」提交迟到复核时，同时附上 POD、签收扫描、预约截图和 ShipTrack 轨迹，证据齐全的案件通过率明显高于只填表单。
常见坑：司机到了仓库却没有有效预约或预约号填错，被直接拒收；除了空驶费和二次派送费，货件还会留下迟到/拒收记录，拉低入仓缺陷率并影响后续时段分配。
运输#302 海运整柜 vs 拼箱的计费与适用场景2026-10-29

整柜（FCL）按箱核算，拼箱（LCL）按货物的计费体积或重量核算；选择时应比较全程费用，而不是只比海运费。

  1. 整柜：适合货量较大、需要独立装柜或希望减少混货操作的货物。即使未装满，也要承担整箱及提还箱等相关费用，因此要看装载利用率。
  2. 拼箱：适合小批量货物，通常按 CBM 或重量吨取大计费，并注意最低计费标准。
  3. 费用差异：拼箱除海运费外，常涉及起运港拼箱费、目的港拆箱费、分拨及文件操作费；低海运费不代表总成本低。
  4. 时效差异：拼箱需要集货、装拼和到港拆箱分拨，可能增加等待环节；整柜流程相对直接，但仍受船期和港口拥堵影响。
  5. 货物管理：易碎、高货值或不适合混装的货物，应综合评估独立装柜的价值。
常见坑：只按“每立方米多少钱”比较，忽略最低收费和目的港拆箱费，到港后账单明显超预算。
FBA#301 FBA 头程渠道选型2026-10-28

不要只比较每公斤单价，应结合补货紧急程度、产品属性和断货成本选择渠道。

  1. 海卡：海运后卡车送仓，适合货量大、能整托派送且补货周期充足的货物；要考虑预约入仓时间。
  2. 海派：海运后转 UPS、FedEx 等快递，操作灵活、免预约送仓；注意超长、超重附加费。
  3. 空派：适合急补货、高货值或季节性商品；询价时确认燃油、旺季及偏远附加费。
  4. 国际快递：适合样品和极急小批量货，通常不是大货长期补货的经济方案。
  5. 组合补货：大部分库存走海运控制成本，少量走空运防止断货。
常见坑：只比较头程运价，漏算末端附加费、预约等待、查验延误和断货损失。
风控#300 如何选择靠谱货代2026-10-27

靠谱不等于报价最低，而是渠道透明、异常处理能力稳定、责任边界清楚。

  1. 核实营业主体、联系方式和实际办公情况，合同主体与收款主体应一致。
  2. 要求报价写清计费重、税费、附加费、时效口径和赔偿规则。
  3. 询问延误、查验、扣关、丢件后的联系人、反馈频率和处理流程。
  4. 首次合作先用小批量试单，核对轨迹、账单与承诺是否一致。
常见坑：只凭微信群里的低价广告发货，出现货损后才发现没有合同、保险或明确赔付依据。
运营#299 物流跟踪与异常处理 SOP2026-10-26

异常处理的关键是尽早发现、固定责任人和保留证据，而不是等客户催促。

  1. 按揽收、起运、到港、清关、提柜、派送、签收设置节点检查。
  2. 轨迹超过正常更新周期仍无变化时，立即向承运商发起查询并记录工单号。
  3. 保存运单、箱单、发票、交接记录、照片和沟通记录，便于索赔。
  4. 给客户同步时说明已知事实、正在采取的动作和下一次反馈时间，不做无依据承诺。
常见坑：只有“正在核实”四个字，没有反馈时点，容易让小延误演变为信任问题。
风控#298 汇率与账期风控2026-10-25

货代利润容易被汇率波动和应收账款侵蚀，报价时应同时管理价格与回款。

  1. 外币成本对应人民币报价时，明确采用的汇率基准和报价有效期。
  2. 汇率波动较大的阶段缩短报价有效期，必要时设置合理的汇率调整条款。
  3. 按客户设置信用额度与账期，逾期后暂停新增赊销，避免风险持续累积。
  4. 定期核对应收账款账龄，区分未到期、逾期和争议款项。
常见坑：只盯销售额和毛利，不看实际回款，账面盈利但现金流持续紧张。
FBA#297 退件与换标操作2026-10-24

退件换标前先做数量、状态和成本评估，避免把不可售库存再次送回仓库。

  1. 取得移除订单明细，核对 SKU、FNSKU、数量和退件原因。
  2. 海外仓收货后清点并拍照，区分可换标、需维修和应报废的货物。
  3. 新标签须覆盖旧标签且保持可扫描，外箱与内品标签不要混用。
  4. 重新创建货件前，核算移除费、仓租、操作费、二次头程和预期销售收入。
常见坑：未核对商品与 FNSKU 对应关系就批量换标，可能造成错标和再次不可售。
FBA#296 库存绩效与库容管理2026-10-23

补货不是越多越好，需要兼顾可售天数、在途库存、滞销风险和仓储成本。

  1. 用现有库存、在途数量和近期销量估算可售天数，再倒推补货时间。
  2. 定期处理不可售和长期滞销库存，减少无效库容占用。
  3. 旺季预留运输延误缓冲，但避免一次性压入过多慢动销库存。
  4. 以后台最新政策、容量监视器和账户通知为准，不沿用过时阈值。
常见坑：只按过去几天销量线性外推旺季需求，忽视活动结束后的销量回落。
FBA#295 FBA 分仓与合仓策略2026-10-22

分仓和合仓应比较总物流成本与操作成本，不能只看仓库数量。

  1. 分仓可能增加票数和不同仓库间的操作协调，但有时更贴近库存配置目标。
  2. 合仓便于集中出货，但需结合后台可选服务、费用和最新仓库安排评估。
  3. 按各仓实际件数、重量和尺寸制作箱唛与申报资料，避免一仓资料套全票。
  4. 出货前比较头程、尾程、贴标、操作和可能产生的额外服务费用。
常见坑：为减少仓库数量盲目合仓，最终综合费用反而更高。
